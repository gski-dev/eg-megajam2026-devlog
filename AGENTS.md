# Devlog repository

This is a public-facing website and editorial repository, separate from the Unreal projects next to it.

- Use HTML, CSS, and JavaScript. The user explicitly requested this stack.
- Build with `npm run build`; check with `npm run check`. The generated `dist/` directory is ignored.
- Keep content under `content/`, HTML templates under `src/`, and browser assets under `public/`.
- Preserve project-path hosting and operation without browser JavaScript. Keep journal search progressive.
- Ground development claims in supplied evidence. Distinguish saved or compiled work from accepted visuals and tested gameplay.
- Curate public summaries. Do not bulk-copy sibling projects, logs, generated assets, credentials, private links, or local absolute paths.
- Do not modify the Unreal project while working on this repository.
- Do not assign a license to third-party assets or the game project without the user's instruction.
