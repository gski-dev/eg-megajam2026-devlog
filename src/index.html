Read the full process ↗
  1. 01

    Idea → research → AI plan

    Develop the faction identities, unit roles, equipment, and animation needs. Turn those decisions into explicit generation and implementation instructions.

  2. 02

    Plans → sprite sheets → Tripo

    Use imagegen for roster sheets and consistent front, left, back, and right references. Feed the four views into Tripo to build the 3D sources.

  3. 03

    Pose sheets → flipbooks → Unreal

    Generate the action poses, check timing in a browser, and use those references to author actions on the imported character rigs.
